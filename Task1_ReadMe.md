# CodSoft UI/UX Internship – Task 1

## 📌 Task: Mobile App Signup Flow

This task required designing a mobile application signup and login flow focused on a clean, intuitive, and user-friendly experience.

---

## 🧠 Objective
- Create a **signup and login UI flow** for a mobile app
- Ensure the design is:
  - Simple and easy to navigate
  - Visually engaging
  - Follows best practices in UX (e.g., clear CTAs, feedback, alternate sign-in)

---

## 🖼️ Screens Designed
1. **Intro Screen** – Welcome interface with logo and CTA to login/signup  
2. **Login Screen** – Input fields for username and password with Apple/Google login options  
3. **Signup Screen** – Input for name, email, password, confirm password with alternative login options  

---

## ✨ Design Highlights
- Consistent use of color and typography
- Easy navigation between login and signup
- Added third-party authentication options (Apple, Google)
- Responsive layout for mobile screen sizes
- Smooth and minimalistic UI for a better user experience
